# Changelog

All notable changes to Android Battery Toolkit will be documented in this file.

The format follows the principles of Keep a Changelog.

## [Unreleased]

### Added

- Initial Android battery information API

- Charging state detection

- Battery health reporting

- Initial unit tests
- Contribution guidelines

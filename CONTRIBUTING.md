# Contributing to Android Battery Toolkit

Thank you for your interest in contributing.

## How to contribute

Contributions are welcome in the following areas:

- Bug fixes
- Android compatibility improvements
- Documentation improvements
- Test coverage
- Performance improvements
- New battery-related utilities
- Feature suggestions

## Reporting an issue

Before opening an issue, please check whether a similar issue already exists.

When reporting a bug, include:

- Android version
- Device model
- Library version
- Steps to reproduce
- Expected behavior
- Actual behavior

Do not include private or sensitive information.

## Pull requests

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Add or update tests where appropriate.
5. Update documentation when necessary.
6. Submit a pull request with a clear description.

## Code style

Please follow standard Kotlin coding conventions and keep changes focused and easy to review.

## Compatibility

The library targets Android API 23 and higher.

Some battery metrics depend on Android version and device hardware. Contributions should gracefully handle unsupported metrics.

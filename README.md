# Android Battery Toolkit

A lightweight, open-source Kotlin toolkit for reading battery information exposed by the Android operating system.

## Features

- Battery percentage
- Charging state
- Battery temperature
- Battery voltage
- Battery current when supported by the device
- Battery technology
- Battery health
- Charging source

## Requirements

- Android 6.0 (API 23) or higher
- Kotlin
- Android Gradle Plugin 8.7+

## Installation

Add the library to your Android project:

```kotlin
dependencies {
    implementation("com.ardhix:batterytoolkit:0.1.0")
}
